# DREAMS1.0 版本紀錄

[開啟版本紀錄 Excel](版本紀錄.xlsx)

依提供的範本，保留兩張表：

- **版本控管紀錄**：版本編號、異動日期、關聯需求編號、異動內容摘要、修改人、狀態、備註。
- **需求管理紀錄**：需求編號、提出日期、客戶/單位、提出人、需求描述、期望完成日、狀態、備註/溝通紀錄。

已移入 1 筆既有版本紀錄。異動日期來自版本文件或程式提交，未核對的發布狀態維持「待確認」。修改人與關聯需求未確認者留白。需求表留待登錄本專案需求。備註儲存格的附註保留原始來源供查閱。

狀態可選「未開始、進行中、待確認、已完成、已取消」，右側會自動統計。範本預留 100 筆；超過時需一併延伸表格、下拉選單、條件格式與統計範圍。

每個倉庫只維護這一份 Excel。GitHub 合併後，以相同檔案同步 SVN，並核對檔案雜湊；同步狀態以內部回執為準。舊版的詳細提交清單保留在 GitHub 歷史版本。
