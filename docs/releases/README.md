# DREAMS1.0 版本與需求紀錄

[開啟 Excel](版本紀錄.xlsx)

依指定範本保留「版本控管紀錄」與「需求管理紀錄」兩張表，目前包含 **1 筆版本紀錄、5 筆需求／修正紀錄**。

內容依版本對應提交及先前盤點的近期 commit 實際程式差異整理；不等同完整歷史需求清單。需求編號在本倉庫內唯一，版本表只關聯有來源支持的需求。合併分支與單純紀錄文件更新不列為產品需求。

需求是依已提交程式回填，並非原始客戶提出紀錄。未有來源的提出日期、客戶／單位、提出人與期望完成日留白。提交日期及短 SHA 列於需求備註，完整 commit 連結與異動檔案在儲存格附註；版本表修改人依 commit 作者填列。已提交不代表已發布或驗收，未核對項目保留「待確認」。

狀態選項沿用範本，右側自動統計。每張表預留 100 筆；超過時需一併延伸表格、下拉選單、條件格式及統計範圍。後續新增提交時，沿用既有需求編號，補入實際功能變更與來源，不把 Excel 維護提交再次當成產品變更。

GitHub 合併後，以相同檔案更新 SVN 原位置並讀回核對；同步是否完成以內部回執為準。
